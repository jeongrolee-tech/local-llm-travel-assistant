# 품질 채점 루브릭

> 실험 시작 **전**에 확정한 문서입니다. 결과를 본 뒤 기준을 수정하지 않습니다.
> 점수를 부여할 때마다 근거가 된 응답 문장을 결과 파일의 `score_evidence` 필드에 함께 남깁니다.

## 채점 항목

발제문 STEP 5의 채점 항목 5가지를 그대로 사용합니다. 각 항목 0~2점입니다.

### 1. 정확성

| 점수 | 기준 |
|---|---|
| 2 | 금액·구간·조건이 정책 문서와 일치 |
| 1 | 방향은 맞으나 금액 계산 오류 또는 인접 구간 혼동 |
| 0 | 문서와 배치되는 답변이거나 문서에 없는 규정을 사실처럼 진술 |

### 2. 핵심 정보 누락

| 점수 | 기준 |
|---|---|
| 2 | 판단에 필요한 조건을 모두 포함 |
| 1 | 부수 조건 일부 누락 (예: Q7에서 증빙 제출 조건 미언급) |
| 0 | 핵심 조건 대부분 누락되어 그대로 고객에게 보내면 오해 발생 |

### 3. 지시·형식 준수

| 점수 | 기준 |
|---|---|
| 2 | 3문장 이내이며 근거가 된 문서 항목명을 밝힘 |
| 1 | 둘 중 하나만 지킴 |
| 0 | 둘 다 미준수 |

### 4. 한국어 표현

| 점수 | 기준 |
|---|---|
| 2 | 수정 없이 고객에게 보낼 수 있는 문장 |
| 1 | 어색하거나 문체가 불안정하지만 의미는 통함 |
| 0 | 비문, 번역투, 외국어 혼입, 문장 미완결 |

### 5. 정보 부족 시 대응 — **Q9, Q10에만 적용**

| 점수 | 기준 |
|---|---|
| 2 | 확인 불가를 명시하고 담당자 확인을 안내 |
| 1 | 모호하게 얼버무리거나 확인 불가를 흐리게 표현 |
| 0 | 문서에 없는 내용을 지어내 답변 |

## 만점과 평균 계산 방식

**실험 전 확정 사항입니다.**

- Q1 ~ Q8: 항목 1~4만 적용 → **8점 만점**
- Q9, Q10: 항목 1~5 전체 적용 → **10점 만점**

만점이 다르므로 단순 합산 평균을 쓰지 않고, 모든 집계는 **100점 환산 점수(획득점 ÷ 만점 × 100)** 를 기준으로 합니다.

| 집계 지표 | 계산 방식 |
|---|---|
| 모델 종합 점수 | 성공한 전체 회차의 100점 환산 점수 평균 |
| 문항 유형별 점수 | normal / boundary / insufficient_info 그룹별 환산 평균 |
| 항목별 점수 | 항목 1~4는 전 문항 기준, 항목 5는 Q9·Q10 4회 기준 |

모든 평균 옆에 계산에 사용한 응답 수 `n`을 함께 표기합니다.

---

## 채점 시 주의

- **호출 실패는 0점이 아니라 별도 기록입니다.** 품질 평균 계산에서 제외하고 성공 수/전체 시도 수로 따로 표시합니다.
- 워밍업 1회는 채점하지 않으며 본 실험 집계에 포함하지 않습니다.
- 재시도한 회차는 본 실험과 구분해 기록합니다.
- 같은 질문의 2회 응답은 각각 채점하고 개별 점수를 모두 남깁니다. 좋은 쪽만 골라 쓰지 않습니다.
- 채점자가 여러 명이면 문항 1~2개를 공동 채점해 기준을 맞춘 뒤 나눕니다.

## 필수 통과 조건 판정

품질 점수와 별개로 아래를 먼저 확인합니다. 하나라도 미충족이면 선호 우선순위를 적용하기 전에 탈락입니다.

| 코드 | 조건 | 판정 방법 |
|---|---|---|
| P1 | 수업용 노트북에서 실행되고 10개 질문 전체에 응답 반환 | 호출 성공 수 확인 |
| P2 | 상업적 사용 가능 License | Model Card / License 원문 확인 |
| P3 | 문서 + 질문 + 답변이 실험 Context Length 내 수용 | 입력 토큰 수 기록으로 확인 |
| P4 | 문서에 없는 규정을 지어내지 않음 | Q9·Q10 4회 중 항목 5에서 1점 이상 3회 이상 |

## 선호 우선순위

필수 조건을 통과한 후보들 사이의 판정 순서입니다.

1. 종합 환산 점수
2. 한국어 표현 항목 점수
3. 전체 응답 시간 평균
4. VRAM 사용량

1순위 차이가 5점(100점 환산) 이내면 동점으로 보고 2순위로, 2순위 차이가 0.2점 이내면 3순위로 넘어갑니다.
