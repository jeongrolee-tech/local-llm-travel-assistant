## 슬라이드 2 — 후보를 어떻게 좁혔나

```
후보 6개 조사
   │
   ├─ EXAONE 3.5 7.8B   라이선스가 연구 전용 (NC)        → P2 탈락
   ├─ Kanana 2 3B       없는 규정을 지어냄               → P4 탈락
   ├─ qwen3.5:4b        중국어 토큰 혼입                 → 제외
   ├─ gemma4:e2b        정답 뒤 "확인 어렵다" 자기모순    → 후순위
   │
   └─ 후보 2개 ──→ 본 실험 40회 (2모델 × 10문제 × 2회)
```

**말할 것**

> "한국어 특화 모델 두 개를 일부러 넣었습니다. Use Case가 한국어니까요. 그런데 **둘 다 필수 조건에서 탈락했습니다.**
>
> EXAONE은 라이선스가 `1.1-NC`, 연구 목적 전용이라 상업적 사용이 안 됩니다. 품질은 재보지도 않고 제외했습니다.
>
> Kanana는 보험 한도를 물었더니 **'3천만원'**, 베트남 비자를 물었더니 **'90일 무비자'**라고 답했습니다. 문서에 없는 내용입니다. 이게 이 과제에서 제일 위험한 실패라 필수 조건으로 잡아뒀고, 거기서 걸렸습니다."

**한 줄 요약:** 한국어 특화라는 축은 이 프로젝트에서 성립하지 않았습니다.

## 슬라이드 3 — 판정 경로 ★핵심

### 1단계. 필수 통과 조건 — 둘 다 통과

| | `qwen3.5:9b` | `gemma4:e4b` |
|---|---|---|
| P1 10문제 전체 응답 | ✅ 20/20 | ✅ 20/20 |
| P2 상업적 사용 가능 | ✅ Apache 2.0 | ✅ Apache 2.0 |
| P3 context 내 수용 | ✅ 27% | ✅ 29% |
| P4 없는 규정 생성 금지 | ✅ 4/4 | ✅ 4/4 |

### 2단계. 선호 우선순위

| 순위 | 지표 | A | B | 판정 |
|---|---|---|---|---|
| 1 | 종합 점수 | 88.1 | 92.9 | 4.8점 차 → **동점 구간(5점 이내)** |
| **2** | **한국어 표현** | 1.65 | **1.95** | 0.30점 차 → **여기서 결판** |
| 3 | 응답 시간 | 1.56초 | 0.91초 | (참고) |
| 4 | VRAM | 5,236 MiB | 3,077 MiB | (참고) |

**말할 것**

> "여기가 이 발표의 핵심입니다.
>
> 점수만 보면 92.9 대 88.1로 B가 이긴 것 같습니다. 그런데 **1순위에서는 결판이 안 났습니다.** 실험 전에 정해둔 규칙이 '5점 이내면 동점으로 보고 다음 순위로 넘어간다'였는데, 차이가 **4.8점**이었습니다.
>
> 그래서 2순위인 한국어 표현으로 넘어갔고, 1.95 대 1.65, 0.30점 차로 갈렸습니다. 3·4순위도 같은 방향이지만 **판정 근거는 2순위입니다.**"

**덧붙일 것 (시간 있으면)**

> "사실 처음 채점했을 때는 차이가 6.0점이라 1순위에서 결판났습니다. 그런데 검토하다가 **같은 결함을 두 항목에서 중복 감점한 걸 발견해서** 6회차를 수정했더니 4.8점이 됐습니다. 선정 모델은 같은데 **근거가 바뀌었습니다.**"

## 슬라이드 4 — 무엇이 갈랐나

### 한국어 표현 감점 — 로컬 A의 5개 회차

> `qwen3.5:9b` Q4 —
> "여권 잔여 유효기간은 출국일 기준 6개월 이상 남아 있어야 한다는 **项规定**가 있으나…"

| 회차 | 사유 | 점수 |
|---|---|---|
| Q4 run2 | **중국어 토큰 혼입** | **0점** |
| Q2 run1·run2 | 마크다운 링크 노출 `([요금 기준](#2.-요금-기준))` | 1점 |
| Q6 run2 | 비문 | 1점 |
| Q10 run1·run2 | 오독 유발 문장 | 1점 |

**말할 것**

> "중국어가 섞였습니다. 20회 중 1회지만 **고객에게 그대로 못 보냅니다.** 상담 직원이 고쳐야 하니까 그게 곧 비용입니다.
>
> 이 프로젝트의 중요 가치 1순위가 '한국어 표현 자연스러움'이라 무겁게 봤습니다. 예비 실행에서 같은 계열 4B를 제외한 이유도 똑같은 현상이었는데, **9B에서도 재현됐습니다.**"

**공평하게 덧붙일 것**

> "반대로 A가 이긴 문항도 있습니다. 만 3세 요금을 물었을 때 A는 `712,000원`까지 계산했고 **B는 '80%를 계산해야 합니다'라고 고객에게 넘겼습니다.** 상담 문의의 다수가 금액 질문이라 이건 B의 실제 약점이고, 운영 권고에 적어뒀습니다."

## 슬라이드 5 — Cloud와 비교

같은 5개 문항 기준

| | 점수 | 응답 시간 | 비고 |
|---|---|---|---|
| `gpt-4o-mini` (Cloud) | **92.9** | 1.48~2.15초 | n=5, 1회 |
| `gemma4:e4b` (선정) | 91.7 | **1.02초** | n=10, 2회 |

| 기준 | 판단 |
|---|---|
| Quality | **Cloud가 1.2점 앞섬** |
| Latency | 로컬 |
| Security | 로컬 — 문서가 장비 밖으로 안 나감 |
| Cost | 호출당 $0.0002. **근거가 되지 못함** |

**말할 것**

> "**Cloud가 더 높았습니다.** 1.2점 차이입니다. 숨기지 않고 그대로 적었습니다.
>
> 그런데도 로컬을 고른 건 **품질이 이겨서가 아닙니다.** 차이가 1.2점이고 반복 수도 다르니(Cloud 1회, 로컬 2회) **동등하다고 보는 게 맞고**, 그 상태에서 정책 문서와 고객 문의가 밖으로 안 나가고 응답도 더 빠르기 때문입니다.
>
> 비용은 호출당 0.0002달러라 일 천 건을 써도 연 47달러입니다. **비용은 로컬을 고를 근거가 못 됩니다.**"

## 질문 대비 카드

### "왜 실패했다는 얘기를 이렇게 많이 적었나요?"

> 발제문이 *"실패 원인이 모델·프롬프트·환경·측정 중 어디에 있는지 구분"* 하라고 요구합니다. 저는 **세 번 원인을 잘못 짚었다가 재검증으로 바로잡았습니다.**
>
> | 오판 | 실제 |
> |---|---|
> | Kanana에 채팅 템플릿이 없다 | `--template`로 확인하니 **공식 템플릿이 내장**돼 있었음. 차이는 샘플링 변동 |
> | 워밍업 효과가 0.86초뿐이다 | 모델이 이미 적재된 상태였음. 실제 로딩은 4.28초 |
> | 채점 항목1·2 양쪽 감점 | **중복 감점.** 수정하니 선정 근거가 1순위→2순위로 이동 |

### "왜 `temperature=0`을 안 썼나요?"

> 실측하니 **반복 2회가 완전히 동일**해집니다. 루브릭의 P4가 "4회 중 3회 이상"인데 4회가 다 같으면 `0/4` 아니면 `4/4`만 나와서 기준 자체가 성립하지 않습니다. 발제문은 값을 지정하지 않아서 저희가 0.2로 정하고 근거를 적었습니다.

### "Cloud가 더 좋은데 왜 로컬인가요?"

> 차이가 1.2점이고 반복 수도 다릅니다. **동등하다고 보는 게 맞습니다.** 그 상태에서 보안과 속도가 로컬 쪽입니다. 그리고 Cloud는 저가 모델 하나만 썼으니 "Cloud 전체보다 낫다"는 뜻은 아닙니다.

### "두 모델을 같이 쓰면 안 되나요?"

> 검토했습니다. A는 계산을 잘하고 B는 안정적이니 질문 유형별로 나누는 구성이요. 그런데 **8GB GPU에서 두 모델이 동시에 안 올라갑니다.** VRAM이 남아도 Ollama 스케줄러가 밀어냅니다. 전환마다 5~6초 로딩이 붙어서 채택하지 않았습니다.

### "Kanana는 정말 모델 문제였나요?"

> 처음엔 GGUF 변환 문제로 의심했습니다. 템플릿을 복원해 재빌드까지 했는데, **프롬프트 토큰 수가 10문항 전부 똑같았습니다.** 입력이 안 바뀌었다는 뜻이죠. `temperature=0`으로 다시 확인하니 Q9·Q10 환각이 그대로 재현됐습니다. **모델 원인이 맞습니다.**

### "실제로 도입할 수 있나요?"

> **현재 구조 — 상담 직원이 초안을 확인하고 발송하는 구조에서는 가능합니다.** P1~P4 전부 통과했고 40회 중 실패가 없습니다. 다만 금액 계산을 회피하는 약점이 있어서 금액 질문은 직원 확인이 필요합니다. 사람 확인 없이 직접 발송하려면 추가 검증이 필요합니다.
