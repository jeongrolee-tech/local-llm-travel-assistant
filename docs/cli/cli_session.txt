## 실행 조건

Python 경로(README 4절)와 같은 입력을 사용했습니다. CLI는 system/user 역할 분리가
없으므로 고정 지시문과 질문을 하나의 프롬프트로 이어 붙였습니다. 따라서 **Python 경로의
측정값과 직접 비교하지 않습니다.** 이 기록의 목적은 CLI 실행 가능 여부 확인입니다.

| 항목 | 값 |
|---|---|
| 입력 | `data/system_prompt.txt` + `data/policy.md` + Q1 |
| thinking | `--think=false` (README 4절 고정 설정과 동일) |
| context / temperature | `ollama run` 기본값 — Python 경로의 `num_ctx=4096`, `temperature=0.2`와 다름 |

질문(Q1): 출발 25일 전에 취소하면 수수료가 얼마인가요?  
기대 결과: 출발 29일 전~20일 전 구간에 해당해 요금의 10%인 89,000원.

## 로컬 A — `qwen3.5:9b`

```
$ ollama run qwen3.5:9b --think=false "<고정 지시문 + 정책 문서 + Q1>"

제공된 자료에 따르면 출발 29 일 전부터 20 일 전까지 취소 시 요금의 10% 가 부
과됩니다.
따라서 출발 25 일 전인 경우 요금 총액의 10% 가 취소 수수료로 적용되겠습니다
.
더 자세한 상담이 필요하시다면 담당 상담원과 직접 연결해 드리겠습니다.

```

소요 6.0초 (모델 로딩 포함, `time` 기준의 벽시계 시간).

```
$ ollama ps
NAME          ID              SIZE      PROCESSOR    CONTEXT    UNTIL              
qwen3.5:9b    6488c96fa5fa    5.5 GB    100% GPU     4096       4 minutes from now
```

```

고객님께서 출발 25일 전에 취소하실 경우, '출발 29일 전 ~ 20일 전' 기준이 적

로 계산하며, 인원별로 각각 적용'된다고 안내되어 있습니다.
```
